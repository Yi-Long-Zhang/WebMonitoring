# 产品范围与 MVP

## 1. 产品定位

WebMonitoring 是面向安全运营、网站运维和业务负责人的网页篡改监测平台。
它不替代 WAF、主机入侵检测或完整漏洞扫描器，重点是回答：

1. 哪个已授权页面发生了异常？
2. 异常具体改变了什么？
3. 变化是否具有恶意特征？
4. 证据在哪里，谁负责处理，是否已经恢复？

## 2. 目标用户

| 用户 | 主要目标 |
| --- | --- |
| 安全运营人员 | 发现、研判、分派和关闭安全事件 |
| 网站运维人员 | 获取差异证据、定位发布或篡改来源 |
| 业务负责人 | 关注重点页面可用性、品牌和业务风险 |
| 审计人员 | 查询告警、证据、操作记录和处置时效 |
| 平台管理员 | 管理租户、资产、角色、节点和通知渠道 |

## 3. 核心流程

```text
按租户（slug）登录
-> 登记站点
-> 登记资产（可选归属站点）
-> 完成授权验证
-> 配置策略
-> 创建或批准基线
-> 定时检测
-> 提取信号
-> 生成风险结论
-> 保存证据
-> 发送告警
-> 事件处置
-> 恢复确认
-> 复盘和报告
```

当前控制面登录可按租户 slug 进入对应租户（空则回落默认租户），平台管理员
（SUPER_ADMIN）可创建租户并播种该租户首个管理员。证据保存必须先于正式告警
发送。告警发送失败不能丢失已生成的事件。

## 4. MVP 功能

### 资产中心

- 租户内页面资产登记、负责人、页面类型和站点归属管理。
- 页面类型：官网、业务前台、后台登录页、其他重点页面。
- 当前实现 HTTP 文件授权验证；DNS 和 HTML 元标签验证待补充。
- 负责人、检测频率、超时、检测节点、启停状态。
- 资产变更审计已具备；批量导入和导出待补充。

### 租户与站点管理

- 站点（Site）CRUD：租户内 ADMIN 可创建/编辑站点；资产可归属站点并按站点过滤。
- 租户（Tenant）CRUD：平台管理员（SUPER_ADMIN）可创建/编辑租户，创建时同时播种
  该租户首个 ADMIN 账号；登录可按租户 slug 进入对应租户。
- super-admin 权限仅限租户 CRUD 与播种租户管理员，不做任意租户数据的全量可见，
  也不做租户硬删除。

### 检测中心

- HTTP 状态、响应时间、大小、响应头、TLS 和 DNS。
- 重定向链、最终域名和最终地址复核。
- HTML 原文摘要和规范化 DOM 摘要。
- 标题、正文、关键区域、脚本、iframe、链接和表单变化。
- 浏览器渲染后的截图、跳转、弹窗和下载行为。
- 超时、响应过大、检测节点失败等检测异常。

### 基线和规则

- 首次检测只产生候选基线，不自动覆盖已批准基线。
- 基线版本可查看、批准、废弃，原版本保留。
- 动态区域、可信资源、维护窗口和误报抑制。
- 规则版本和风险评分记录在每次检测结果中。

### 事件中心

- 事件去重和相同异常聚合。
- 风险级别：提示、低、中、高、严重。
- 认领、指派、备注、误报、处理中、已恢复、已关闭。
- 证据清单和操作审计已具备；完整事件时间线待补充。
- 当前支持企业微信和 Webhook；钉钉、邮件适配器待补充。

### 报告中心

- 单事件证据包。
- 时间范围、资产范围和风险范围报告。
- 检测覆盖率、告警数量、平均发现时间和平均恢复时间。

## 5. 非目标

第一阶段不实现：

- 未经资产登记的开放式扫描。
- 漏洞利用、密码破解、绕过认证和攻击验证。
- 自动修改客户网站或基础设施。
- 以大模型替代规则、哈希、DOM、网络和浏览器信号。
- 不具备审计和回滚能力的批量删除。
- 未经容量验证的微服务、分布式爬虫和大数据平台。

## 6. MVP 验收标准

- 可在租户内登记一个已授权 URL，并完成基线审批。
- 正常动态内容可以通过配置被忽略。
- 新增外部脚本、恶意跳转和明显内容替换可产生可解释事件。
- 每个事件都能查看原始证据、差异和规则版本。
- 重复检测不会重复创建相同事件或告警。
- 事件状态、负责人和处置记录可审计。
- 检测目标、证据和通知失败时均有明确错误状态。

## 7. 关键指标

初始阶段不设脱离真实样本的绝对准确率承诺，先建立可测量基线：

- 授权资产检测成功率。
- 证据完整率。
- 高风险事件的证据关联率。
- 重复事件率。
- 误报率及误报关闭原因分布。
- 平均发现时间（MTTD）。
- 平均确认时间（MTTA）。
- 平均恢复时间（MTTR）。

## 8. 产品决策

所有高风险告警必须是“辅助研判”，不是“自动定罪”。产品文案应使用
“检测到疑似”“命中以下信号”“建议核查”等可验证表达，避免无证据的
绝对结论。
